# MyBBResources

A community for people who build, customize, and run MyBB forums.

Find help, share knowledge, and explore community resources for your forum:

- **Support** — ask questions and help other MyBB users
- **Plugins and mods** — discover ways to extend forum features
- **Themes** — share and find looks for MyBB communities
- **Community** — exchange tips, ideas, and improvements

MyBBResources is an independent community project and is not affiliated with the MyBB project.
